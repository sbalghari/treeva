# Changelog

All notable changes to Treeva will be documented in this file.

The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1a1] - 2026-07-23

### Added

- **Tree-sitter code analysis**: AST-based parsing for 10 languages (Python,
  Rust, Go, JavaScript, TypeScript, Bash, Lua, Java, C++, C) with precise
  comment, LOC, and blank-line classification
- **Code metrics**: Per-file structural metrics — functions, classes, methods,
  variables, constants, imports, branches, loops, returns, exceptions, nesting
  depth
- **Symbol extraction**: Named symbol (function/class) discovery with start/end
  line ranges for all tree-sitter languages
- **Dependency graph**: Import extraction via tree-sitter queries for 9
  languages; `build_dependency_graph()` for project-wide dependency maps
- **Git analysis**: `git log --numstat` integration for churn/hotspot detection
  (`GitChurn`, `GitAnalysis`)
- **Metrics aggregation**: `MetricsAggregator` accumulating per-file
  `CodeMetrics` into project-level `ProjectMetrics`, sorted by language
- **Analysis manager**: `AnalysisManager` orchestrating dir walk → factory →
  analyzer → aggregator pipeline, producing `AnalysisResult`
- **Analysis result model**: Unified `AnalysisResult` with project stats, code
  metrics, language distribution, complexity scores, scan metadata, and
  JSON/plain-text serialization
- **Per-directory AGENTS.md**: Recursive `AGENTS.md` generation for every
  subdirectory with file tables and symbol listings
- **AGENTS.md marker boundaries**: Warning comments
  (`<!-- Start/End - Generated By Treeva -->`) isolating treeva-managed
  content; marker-aware writes preserve user edits outside markers
- **AGENTS.md root structure**: Project Overview (description, version, total
  files/LOC by language), Tech Stack (libraries from pyproject.toml), Directory
  Structure (visual tree), Root Files table with filetype, description, and
  lines columns, Directory Map, Agent Rules
- **Import counting**: `import_count` in `CodeMetrics` with tree-sitter
  import/use/include node mapping for all supported languages
- **Non-code file line counts**: Physical line counts tracked for config, doc,
  and other non-code files via direct byte-count fallback
- **`cli/utils/` module**: CLI utilities organized under `cli/utils/` —
  `_base.py` (panel/msg helpers), `console.py` (Catppuccin-themed Rich
  console), `output.py` (rich table rendering for files/dirs/analysis),
  `spinner.py` (live spinner context manager)
- **`cli/format.py`**: Output formatting (`source_file_format_*`,
  `dir_node_format_*`) separated from analysis logic into dedicated CLI format
  module
- **`cli/app.py`**: All CLI commands (`analyze`, `dir`, `file`, `agents`)
  consolidated in a single app module; root `__init__.py` re-exports `cli`
- **Model layer**: Dedicated model modules — `SourceFile`, `DirNode`,
  `CodeMetrics`, `AnalysisResult`, `ProjectMetrics`, `ParserResult`, `Symbol`,
  `TreeStats`, `ErrorSpan`
- **Constants layer**: Organized under `constants/` — `FileCategory`/`FileType`
  enums (44 types across code/script/config/doc/other), `FILE_EXTENSIONS`
  mapping (41 entries), `DEFAULT_EXCLUDES` (60+ patterns), Catppuccin Mocha
  theme in `theme.py`
- **Library module**: `library/` with `exceptions.py` (6 exception classes),
  `logger.py` (Rich rotating-file logging), `utils.py` (`format_size`,
  `is_hidden`), `version.py`
- **Pre-commit hook**: `.githooks/pre-commit` for auto-formatting with ruff and
  prettier
- **Test suite**: 47 tests across tree-sitter analyzer, grammars, mapping,
  walker, symbols, dependencies, and git analysis with fixtures for 9 languages
  (valid, broken, edge-case files)
- **uv.lock**: Dependency lockfile for reproducible builds

### Changed

- **Project structure reorganized**: `src/treeva/lib/` split into `analysis/`,
  `constants/`, `library/`; models moved from flat files to `models/` package
- **CLI output overhauled**: Rich table rendering with multi-column layouts,
  gradient ASCII art, themed panels for info/success/error/warning; `output.py`
  expanded from minimal to 398 lines
- **\`src/treeva/scanners/loc.py\` removed**: Replaced by tree-sitter analyzer
  with language-specific comment detection
- **Models renamed**: `FileInfo` → `SourceFile`, `DirInfo` → `DirNode`,
  `AnalysisInfo` → `AnalysisResult` with expanded fields
- **Exclusion system**: `UnionExclude` combining default + gitignore rules;
  `AGENTS.md` excluded from scanning
- **README.md trimmed**: Documentation reduced in favor of auto-generated
  AGENTS.md

### Removed

- **`src/treeva/lib/`**: Split into `analysis/`, `constants/`, `library/`
- **`src/treeva/lib/constants.py`**: Replaced by `constants/excludes.py`
- **`src/treeva/lib/enums.py`**, **`types.py`**, **`exceptions.py`**: Moved to
  their respective new modules
- **`src/treeva/lib/README.md`**: Deleted
- **`src/treeva/models/analysis_info.py`**: Replaced by `analysis_result.py`
- **\`src/treeva/scanners/loc.py\`**: Legacy LOC calculation, superseded by
  tree-sitter
- **`ROADMAP.md`**: Deleted from project root

### Fixed

- **Comment density**: `MetricsAggregator` now correctly multiplies by 100 for
  percentage
- **AGENTS.md duplication**: Marker-based writes prevent content duplication on
  repeated `treeva agents .` runs
- **`sys.exit()` calls**: Removed from library code; exceptions bubble to CLI
  layer

## [0.1.0-alpha] - 2026-05-11

### Initial Alpha Release

#### Added

- **Core Scanning**: Recursive directory traversal with filesystem error
  handling
- **File Metadata**: Comprehensive file information extraction (size,
  permissions, timestamps, ownership)
- **Language Detection**: Support for 40+ programming languages with
  extension-based detection
- **Lines of Code (LOC) Calculation**: Language-specific comment detection for
  code metrics
  - Single-line comment recognition
  - Multi-line comment block detection
  - Language-specific docstring handling
- **Directory Aggregation**: Recursive metrics aggregation including:
  - File counts and directory statistics
  - Total size calculations
  - Language distribution tracking
  - Timestamp ranges (oldest/newest files)
  - Permission classifications (executable, read-only)
- **Code Quality Metrics**:
  - Comment density percentage calculation
  - Code quality scoring (0-100 scale)
  - Project complexity classification
- **CLI Commands**:
  - `analyze`: Full project analysis with quality scoring
  - `dir`: Directory-level metadata
  - `file`: Single file inspection
- **Output Formats**:
  - JSON: Structured data output
  - Plain Text: ASCII-formatted reports
  - Rich Table: Colored terminal tables with Rich library styling
- **Exclusion Rules**:
  - Built-in exclusion patterns for common directories
  - Gitignore-style pattern matching support
- **Logging**:
  - Platform-aware logging with user-local directories
  - Rotating file handlers
  - Debug-level verbosity support
- **Type Safety**: Full type hints with mypy validation
- **Cross-Platform Support**: Works on Linux, macOS, and Windows
