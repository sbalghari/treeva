# Changelog

All notable changes to Treeva will be documented in this file.

The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- **Structural code metrics**: function, class, method, variable, constant,
  branch, loop, return, and import counts; max/average nesting depth extracted
  from ASTs instead of regex heuristics
- **Per-section AGENTS.md generator**: `generate` command with
  `--target agents`, `--update`, `--remove`, and repeatable `-s` flag to scope
  generation to named sections; per-directory marker blocks
  (`<!-- Start - Generated By Treeva [<section>], ... -->`) so hand-edited
  content outside markers is preserved
- **`inspect` command**: replaces the old `dir` and `file` commands with a
  single unified command for file or directory metadata
- **`--exclude` / `-e` flag**: extra gitignore-style exclude patterns accepted
  by `analyze`, `inspect`, and `generate` commands
- **`--no-rich` flag**: global option to disable Rich rendering for plain-text
  fallback
- **Directory structure metrics**: `DirStructure` model tracking deepest
  directory depth, average files per directory, and empty directory count
- **`ScanMetadata` model**: scanned/ignored/failed file counts and scan
  duration
- **`LargestEntities` model**: largest file, function, and class with paths and
  line counts
- **`DocumentationInfo` model**: documented/undocumented function, class, and
  method counts with `docs_coverage` property
- **`LanguageStatistics` model**: top languages (sorted by LOC), distribution
  percentages, and per-language LOC
- **`CodeQuality` model**: cyclomatic complexity and maintainability index
- **`CodeMetrics` model**: aggregated LOC, comment, blank line counts, all
  structural metrics, and `comment_density` property
- **Tree-sitter models**: `ParserResult`, `Symbol`, `TreeStats`, `ErrorSpan`
  dataclasses for parse results
- **Tree-sitter AST analysis**: structural code metrics for 10 languages
  (Python, Rust, C, C++, Go, Java, JavaScript, TypeScript, Lua, Bash) via
  `analysis/treesitter/` pipeline — grammars, walkers, analyzers, and
  per-language node-kind mappings

### Changed

- **CLI modularized**: monolithic `cli/__init__.py` split into `cli/app.py`,
  `cli/commands/*`, `cli/formats/*`, and `cli/output/*` packages; each command
  registers via `register(app)`
- **Constants split** into `constants/enums.py`, `constants/excludes.py`,
  `constants/extensions.py`, and `constants/theme.py`
- **Models refactored** to pure dataclasses with nested sub-models under
  `models/analysis/`; `DirInfo` and `FileInfo` stripped of business logic
  (`from_path`, `_format` methods removed)
- **`scanners/exclusions.py`** overhauled: `ExcludeRule` ABC with
  `should_exclude()` protocol; `UnionExclude` combines default and gitignore
  rules; `_build_extra_spec()` compiles user patterns
- **`scanners/dir_walker.py`** rewritten: accepts `extra_exclude_patterns`,
  uses in-place `dirs[:]` mutation to skip entire subtrees, no double-walk
- **Package dependencies updated**: added `tree-sitter` and 10 grammar
  packages, `requests`; Python floor bumped to `>=3.12`; entry point moved to
  `treeva.cli:app`
- **`AnalysisResultFormat.json()`** now produces nested dict mirroring
  dataclass hierarchy instead of a flat key-value dict

### Fixed

- **`comment_density` in aggregator**: now correctly multiplies by 100 to
  produce percentage values (was returning raw 0.0–1.0 ratio)

### Removed

- **`dir` and `file` CLI commands**: replaced by unified `inspect` command
- **`git` and `deps` CLI commands**: removed along with their analysis and
  model backends; git support degrades silently, deps never stabilized
- **`scaners/` directory**: renamed to `scanners/` with corrected spelling
- **`CalcLOC` class**: removed in favor of tree-sitter-based LOC counting
- **Monolithic `cli/output.py`**: replaced by `cli/output/` package with
  `__init__`, `_base`, `console`, and `spinner` modules
- **Monolithic `constants.py`**: replaced by `constants/` package
- **Monolithic `__init__.py`**: removed `cli` entry point (now in `cli/app.py`)

## [0.1.0-alpha] - 2026-05-11

### Added

- **Core Scanning**: Recursive directory traversal with filesystem error
  handling
- **File Metadata**: Comprehensive file information extraction (size,
  permissions, timestamps, ownership)
- **Language Detection**: Support for 40+ programming languages with
  extension-based detection
- **Lines of Code (LOC) Calculation**: Language-specific comment detection for
  code metrics
  - Single-line comment recognition
  - Multi-line comment block detection
  - Language-specific docstring handling
- **Directory Aggregation**: Recursive metrics aggregation including:
  - File counts and directory statistics
  - Total size calculations
  - Language distribution tracking
  - Timestamp ranges (oldest/newest files)
  - Permission classifications (executable, read-only)
- **Code Quality Metrics**:
  - Comment density percentage calculation
  - Code quality scoring (0-100 scale)
  - Project complexity classification
- **CLI Commands**:
  - `analyze`: Full project analysis with quality scoring
  - `dir`: Directory-level metadata
  - `file`: Single file inspection
- **Output Formats**:
  - JSON: Structured data output
  - Plain Text: ASCII-formatted reports
  - Rich Table: Colored terminal tables with Rich library styling
- **Exclusion Rules**:
  - Built-in exclusion patterns for common directories
  - Gitignore-style pattern matching support
- **Logging**:
  - Platform-aware logging with user-local directories
  - Rotating file handlers
  - Debug-level verbosity support
- **Type Safety**: Full type hints with mypy validation
- **Cross-Platform Support**: Works on Linux, macOS, and Windows
