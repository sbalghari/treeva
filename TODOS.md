## ✅ Done since v0.1.0a1 — Codebase overhaul

- [x] **Tree-sitter code analysis**: AST-based parsing for 10 languages
      (Python, Rust, Go, JS, TS, Bash, Lua, Java, C++, C) with
      comment/LOC/blank-line classification
- [x] **Code metrics**: Per-file structural metrics — functions, classes,
      methods, variables, constants, imports, branches, loops, returns,
      exceptions, nesting depth
- [x] **import_count**: Added `import_count` field to `CodeMetrics` with
      tree-sitter import/use/include node mapping for all supported languages
- [x] **Symbol extraction**: Named symbol (function/class) discovery with
      start/end line ranges for all tree-sitter languages
- [x] **Dependency graph**: Import extraction via tree-sitter queries for 9
      languages; `build_dependency_graph()` for project-wide dependency maps
- [x] **Git analysis**: `git log --numstat` integration for churn/hotspot
      detection (`GitChurn`, `GitAnalysis`)
- [x] **Metrics aggregation**: `MetricsAggregator` accumulating per-file
      `CodeMetrics` into project-level `ProjectMetrics`, sorted by language
- [x] **Analysis manager**: `AnalysisManager` orchestrating dir walk → factory
      → analyzer → aggregator pipeline, producing `AnalysisResult`
- [x] **Analysis result model**: Unified `AnalysisResult` with project stats,
      code metrics, language distribution, complexity scores, scan metadata
- [x] **Per-directory AGENTS.md**: Recursive AGENTS.md generation for every
      subdirectory with file tables and symbol listings
- [x] **AGENTS.md markers**: Warning comment boundaries
      (`<!-- Start/End - Generated By Treeva -->`) isolating generated content;
      marker-aware writes preserve user edits outside markers
- [x] **AGENTS.md root structure**: Project Overview, Tech Stack, Directory
      Structure tree, Root Files table, Directory Map, Agent Rules
- [x] **Non-code file line counts**: Physical line counts tracked for
      config/doc/other files via byte-count fallback
- [x] **CLI refactor**: `cli/*` → `cli/utils/`; formatting moved from
      `analysis/factories.py` → `cli/format.py`; all CLI commands moved from
      root `__init__.py` → `cli/app.py`
- [x] **Type fix**: `scaners` → `scanners` directory rename +
      `_normalise_import_text` → `_normalize_import_text`
- [x] **Model layer**: Dedicated modules — `SourceFile`, `DirNode`,
      `CodeMetrics`, `AnalysisResult`, `ProjectMetrics`, `ParserResult`,
      `Symbol`, `TreeStats`
- [x] **Constants layer**: `constants/` — `FileCategory`/`FileType` enums (44
      types), `FILE_EXTENSIONS` (41 entries), `DEFAULT_EXCLUDES` (60+
      patterns), Catppuccin Mocha theme
- [x] **Library module**: `library/` — exceptions (6 classes), logger (Rich
      rotating-file), utils (`format_size`, `is_hidden`), version
- [x] **Exclusion system**: `UnionExclude` combining default + gitignore rules;
      AGENTS.md excluded from scanning
- [x] **ROADMAP.md deleted**
- [x] **Test suite**: 47 tests across analyzer, grammars, mapping, walker,
      symbols, dependencies, git with fixtures for 9 languages
- [x] **Pre-commit hook**: `.githooks/pre-commit` for auto-formatting with
      ruff + prettier
- [x] **CHANGELOG.md**: Populated with all changes since `v0.1.0a1`
